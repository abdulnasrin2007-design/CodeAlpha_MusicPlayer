# CodeAlpha Music Player 🎵

A responsive web-based audio player application built with HTML, CSS, and JavaScript.

---

## 📌 Features

* **Audio Playback:** Play, pause, skip, and navigate through tracks seamlessly.
* **Custom UI:** Clean interface with custom controls and album artwork support.
* **Playlist Structure:** Local storage of audio files and images for smooth assets loading.
* **Responsive Layout:** Adaptive design that works across different screen sizes.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
* **Media:** Audio files (MP3/WAV) & Image assets (JPEG/PNG)
